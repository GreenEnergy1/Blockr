What actually happens when you add a site

No filtering service, no DNS provider to switch to — the block happens on your own machine, in three steps.

01

You add a domain

Paste one site or a whole list — separated by commas or new lines — into Blockr and select Add Sites.

02

Blockr rewrites the hosts file

It appends two lines per domain, the bare version and the www. version, both pointed at 127.0.0.1 and tagged #BLOCKR so they're easy to find later.

03

The lookup dead-ends

Windows checks the hosts file before it ever asks a DNS server. The domain resolves to your own computer — no page, no request, nothing to load.

Harder to undo than an extension

A browser extension is one click away from being disabled. Blockr sits behind an administrator prompt and a system file instead — reversing a block means opening the app, selecting the exact domain, and choosing Remove Selected. That extra step is deliberate.

It also means the block holds across every browser on the machine at once, since the redirect happens before any of them get involved.

Get it running

Two ways to install, depending on how much you trust a stranger's .exe.

Download the build

Windows only. The app requests administrator access on launch, since it needs to edit a protected system file. 

# grab the latest release, then run it —
# Windows will prompt for elevation
blockr.exe

Run from source

Requires Python 3.10+ and PyQt6.

py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install PyQt6
python blockr.py

One file, edited on purpose.
